# GameUpdates
A Game Info Application

Basic web application built with the goal of taking a simple unoriginal idea to learn a full-stack web development stack, then learning to scale it to something more.
___

## Currently you can
Search for game releases 
Add and save game releases to lists.

## Future features
Custom list creation
Customisable profile pages
Friends
Messaging
Share lists
General game news
User-specific news, releases and any other info based on played games and marked/predicted interests in genres and otherwise.
